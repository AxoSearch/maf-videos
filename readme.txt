=== Vidéos MAF ===
Version : voir maf-videos.php (mises à jour automatiques depuis GitHub)

Gère les vidéos de Mon Appart Facile à un seul endroit (menu « Vidéos » de l'administration).

Une vidéo = une fiche : le lien YouTube suffit. Le titre, la miniature et le format (court ou détaillé) se remplissent tout seuls.
Cases « Mettre en avant sur la home » : téléphones du haut de page (3 formats courts), carte YouTube du haut de page (1 vidéo détaillée), section vidéo de la home.

Codes courts (à placer dans un bloc « Code court ») :
[maf_videos_hero]                 les 3 téléphones et la carte YouTube du haut de la home
[maf_videos_home]                 les onglets « Formats courts / Vidéos détaillées » de la home (5 courts, 4 détaillées)
[maf_videos_page type="long"]     toutes les vidéos détaillées (page Vidéos)
[maf_videos_page type="court"]    tous les formats courts avec filtres par thème (page Vidéos)
[maf_videos_nombre]               nombre de vidéos enregistrées

Lecture : la miniature vient de YouTube ; le lecteur (youtube-nocookie.com) ne se charge qu'au clic, dans une fenêtre.
